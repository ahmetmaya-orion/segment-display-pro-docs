    Frequently Asked Questions¶

    Quick answers to the most common questions about Segment Display Pro and Segment Display Lite.

    The Lite Edition¶

    Is there a free version of the Segment Display add-on?

    Yes. There is a free version of the add-on called "Segment Display Lite". The Lite version is not a demo product. It's just a simplified variant with some limited features compared to the Pro version, for anyone who wants to discover the add-on. You can review the Edition Features Table to compare both versions.

    Does Segment Display Lite have a time trial period?

    No, the free version has no time trial. You can use it until a large asteroid hits the Earth!

    Will the Lite version receive updates in the future?

    No. For major future updates and releases, we focus all our efforts on the Pro version. The Lite version will only receive occasional hotfix patches.

    Are the Lite and Pro versions independent add-ons?

    Yes, they are completely different add-ons; both editions have their own assets and plugins. You do not have to install the Pro version on top of the Lite version. Both can be used on the same system. Keep in mind that you cannot control a Lite object through the Pro N-panel interface, and vice versa.

    Installation & Updates¶

    Which Blender versions are supported?

    v1.0.1 and later

    SegDisp v1.0.1 has been tested with Blender 5.1.2, the recommended version for this release. The declared minimum is Blender 5.1.1, but v1.0.1 has not yet been re-tested on that version. Newer Blender versions are not confirmed as supported yet. The add-on runs on Windows, macOS and Linux (tested on Windows 11 only), and works with both the Cycles and EEVEE render engines. If a future add-on update needs a newer Blender version, the add-on will notify you. See the Installation & Activation page for the full system requirements.

    How do I update the add-on without losing my activation?

    Install the complete matching ZIP over the old version with Target Path set to Default and Overwrite enabled, then restart Blender. Your activation file is outside the add-on folder. Reopen and inspect your project first: displays often return automatically. For Pro v1.0.1 and later, use Review & Recover… only if supported issues remain after the installed asset is available. See Updating the Add-on.

    Does Check for Updates install the update?

    v1.0.1 and later

    No. Check for Updates only checks whether a newer version is available. If there is one, Open Downloads opens the download page in your browser. Nothing is downloaded, installed or restarted for you. Download the new ZIP, install it over your current version, then restart Blender. See Add-on Update and Updating the Add-on.

    How do I repair displays after an update or reinstall?

    Pro v1.0.1 and later

    If displays appear as planes, preserve a project copy and leave their modifiers untouched. Reinstall the complete matching add-on and restart Blender first; this often restores displays without manual recovery. If problems remain, use Preferences > Add-ons > Segment Display Pro > Asset Status > Review & Recover…. Review the actions and backup option, recover, inspect settings/animation and save.

    Reconnection uses data still present. Deleted settings and animation cannot be restored by assigning a node tree again or recreating a modifier with defaults. Lite uses a different recovery procedure, not covered here. See Review & Recover.

    Why is Add unavailable after updating?

    Restart Blender first, then check Asset Status. Not Available means the installed asset cannot be used; Unknown version information needs checking, and a known asset/add-on version mismatch can block adding displays. Reinstall the complete matching package rather than mixing asset/script versions or editing modifiers. See asset troubleshooting.

    Why did Blender stop responding during recovery?

    Blender can pause while recovery relocates and reloads an asset library whose path points outside the current installation. Allow it to finish; duration varies and a temporary not-responding message does not necessarily mean a crash. This involves Blender's library handling; the exact bottleneck is unconfirmed. See recovery pauses.

    Licensing & Usage¶

    Does the add-on require a license key to be activated?

    Yes. Both the Lite and Pro versions require license activation through your Lemon Squeezy account. After purchasing, you'll need to activate your license key to use the add-on. You can manage your license and activations directly from your Lemon Squeezy account dashboard.

    How many devices can I activate my license on?

    Each Segment Display Pro license key includes 3 activations (Segment Display Lite includes 1). Every time you activate the add-on on a new device, it counts toward your limit. If you need to move your license to a different machine, make sure to deactivate it on the old device first.

    Important

    Uninstalling the add-on without deactivating does not free up the activation slot. If you accidentally uninstall without deactivating, you can free up the slot yourself from your Lemon Squeezy order dashboard.

    Does the add-on work on render farms?

    Render-farm workflows have not been tested with SegDisp, so compatibility, setup requirements and activation requirements for render nodes are not confirmed. We cannot currently guarantee that projects using live procedural SegDisp objects will render correctly on a cloud or network render farm.

    You can apply the display's Geometry Nodes modifier and use the resulting mesh outside Blender, as explained under Sharing & Exporting. This is allowed, but it is not a tested render-farm workflow.

    Can I use the add-on in commercial projects?

    Yes. Segment Display Pro uses a dual license:

    • Add-on code (GPL v3): You're free to use, copy, and modify the code for your own pipeline. If you distribute a modified version, you must pass on the same freedoms and source code.
    • Assets (Single User Commercial License): The supplied asset .blend file remains the property of Orion November Studio and must not be redistributed, sold, shared, sub-licensed, or uploaded, in original or modified form. This restriction does not prevent you from using your generated SegDisp objects in commercial projects, including applying their modifiers and exporting the resulting meshes for use in game engines or other software.

    In short: you can use your renders and generated display meshes in your projects; you cannot redistribute the supplied asset .blend file. Full details are in our license terms.

    Add-on In Action¶

    Why does the add-on link assets instead of appending them to the scene?

    The Segment Display Geometry Nodes asset references numerous external objects and collections required for correct functionality. Appending the asset would automatically import all of those external objects into the scene, with no way to preserve the original collections and sub-collections hierarchy, leaving the Outliner cluttered and difficult to manage. Linking also offers an additional advantage: any future updates made to the asset in the source file are automatically reflected in the scene, eliminating the need to re-import.

    What are the segdisp_* custom properties on my Pro object?

    They are recognition/recovery metadata, not display controls. Leave segdisp_type, segdisp_schema, segdisp_edition and segdisp_modifier intact, and do not manually rename/delete the SegDisp modifier. An object's identity does not always identify its correct empty modifier; ambiguous targets require Needs Review. See recognition properties.

    Why are segment value results not shown in solid shading mode when the display base is toggled?

    The LED part of the segment display object is a solid mesh aligned over the display base and visible via an emission material, which is not noticeable in solid mode. If you want to see the value results, you may have to switch to the material or rendered view. However, if you are working in a busy scene and don't want to lose viewport performance, you can toggle the "Solid Viewport Preview" button in the "Viewport & Overlays" add-on panel to see the results in solid view. See Viewport & Overlays for details.

    Info

    The Solid Viewport Preview sets the viewport object color to "Attribute (Vertex)", which affects the entire scene.

    Why are there two different options for the Numbers category?

    Blender stores number inputs as single-precision floats (float32), which limit the precision of a single input. SegDisp Pro's Simple input supports values up to 10,000,000; an 8-digit display does not mean every 8-digit value is supported.

    That's why the Numbers category offers two input options:

    • Simple: A single input field for everyday values, with up to 8 display digits and a maximum input value of 10,000,000.
    • Complex: Builds the current number from five three-digit input groups, each accepting 0-999, for up to 15 display digits. These are not fixed decimal or place-value separator groups. Display Length determines which groups remain active, while Decimals and Decimal Length determine decimal formatting. The rightmost group [1] remains active for whole numbers when Decimals is off.

    See the Troubleshooting page for details.

    Animation & Rendering¶

    Can I animate the display values?

    Yes. Most N-panel inputs can be keyframed like any other Blender property: hover over a value and press I. The Time category also includes built-in auto animations (Clock and Timer), so you don't have to keyframe anything for clocks and countdowns. Since Blender can't animate text inputs, the Alphanumeric category uses a built-in multi-input preset system to switch between words over time. See the Alphanumeric page for more details.

    Does it render in both Cycles and EEVEE?

    Yes, both engines are supported. In EEVEE, enable Raytracing in Properties > Render Properties so the segment emission lights up the scene the way it does in Cycles. More tips are on the Troubleshooting page.

    Why is my timer drifting at 29.97 fps?

    The auto time animations (Clock, Timer), including Clock Start Frame and Timer Start Frame, only work correctly with whole-number frame rates such as 24, 25, 30, or 60. Decimal frame rates like 23.98 or 29.97 cause small timing errors because of how Blender converts frames to time. Also, make sure the "Addon Frame Rate" dropdown in the N-panel matches your scene's frame rate. See the Preferences & Settings page for details.

    Sharing & Exporting¶

    Can I link a SegDisp object from another project?

    This workflow is not currently validated. Configure and animate displays in their owning project; repair and save that source before reloading its library in the destination. Recovery does not directly edit source-linked modifiers. Lite testing showed input-type errors after library reload; restarting cleared the observed error but is not a guaranteed fix or a confirmed Pro defect. Linked-object still and animation rendering remain unverified. See linking limitations.

    Can I share my .blend file with someone who doesn't own the add-on?

    Yes, if you share the generated display as an applied or converted mesh rather than redistributing the supplied asset .blend file. Work on a copy if you want to keep the original procedural display editable.

    An unapplied SegDisp object still depends on the linked asset file in the add-on installation and may appear as a plane when that file is unavailable. To continue editing it procedurally, your teammate needs their own copy of the matching add-on edition and its assets; Lite cannot control Pro objects. Do not pack or include the supplied asset .blend file as a way to bypass that requirement.

    Can I export to Unity, Unreal or FBX?

    Yes. Apply the SegDisp object's Geometry Nodes modifier to convert the generated display into a mesh, then export it in a format supported by your target software, such as FBX, for use in Unity, Unreal or other game engines. Work on a copy if you want to retain the original procedural display.

    Applying the modifier captures the current geometry; it does not automatically transfer SegDisp's procedural controls or Geometry Nodes-driven animation to another application. Exporting your generated display mesh is allowed. The restriction is on redistributing the supplied asset .blend file, not on exporting SegDisp objects.
