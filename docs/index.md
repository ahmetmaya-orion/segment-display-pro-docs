# Segment Display Pro

User manual for the Segment Display Blender add-on.

## Overview

Segment Display Pro is a Blender add-on for creating and controlling
seven-segment style displays directly inside Blender.

## Development

This documentation site is built with [MkDocs](https://www.mkdocs.org) and the
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material) theme.

To preview locally:

```sh
pip install -r requirements.txt
mkdocs serve
```

To build the static site:

```sh
mkdocs build
```
